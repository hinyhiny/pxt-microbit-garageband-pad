# 表現とその他

キーボードにあってボタンに無いもの——音を曲げる、サステインペダル——を足すブロックと、
全部を一発で止めるブロックです。

## 傾き

本体は自分がどちらに傾いているかを知っています。6 方向のうち 2 方向を使い、どちらも
演奏中に読み続けるので、和音を鳴らしながら曲げられます。

```
   左右の傾き（ロール） -> ピッチベンド
      -90           0           +90
   ────┬───────────┬───────────┬────
     -2 半音     変化なし      +2 半音

   手前／奥の傾き（ピッチ） -> モジュレーション（ビブラート）
      -90           0           +90
   ────┬───────────┬───────────┬────
      CC1 = 0                 CC1 = 127
```

傾きは **25 ミリ秒ごと**に読むので、段階ではなく滑らかな曲がりに聞こえます。

## 傾きでピッチベンド

本体を左右に傾けて、鳴っている音の高さを曲げます。

```sig
gbpad.tiltPitchBend(OnOff.On)
```

**パラメータ**

* **mode**: `オン` で傾きに追従、`オフ` で止める

```blocks
gbpad.tiltPitchBend(OnOff.On)
```

いっぱいまで傾けると **2 半音**ほど曲がります。ギターのチョーキングと同じ幅です。
`オフ` にすると曲がりが中央に戻るので、音がずれたままになりません。

## 傾きでモジュレーション

本体の傾きでモジュレーション（ビブラート）をかけます。MIDI コントロールチェンジ 1 を
使います。

```sig
gbpad.tiltModulation(OnOff.On)
```

**パラメータ**

* **mode**: `オン` で傾きに追従、`オフ` で止める

```blocks
gbpad.tiltModulation(OnOff.On)
```

傾きがビブラートになるかトレモロになるか、それとも別の効果になるかは、
GarageBand で選んだ音色によります。

## サステインペダル

サステインペダルを踏む / 離します（MIDI コントロールチェンジ 64）。

```sig
gbpad.sustain(OnOff.On)
```

**パラメータ**

* **mode**: `オン` で踏む、`オフ` で離す

```blocks
gbpad.onPadPressed(MidiPad.Logo, () => {
    gbpad.sustain(OnOff.On)
})
gbpad.onPadReleased(MidiPad.Logo, () => {
    gbpad.sustain(OnOff.Off)
})
```

本物のペダルと同じで、踏んでいる間に弾いた音は、パッドを離したあとも鳴り続けます。

## すべての音を止める

鳴っている音を全部止め、「RTTTL を再生」で鳴っている曲も止め、パッドの状態も
リセットします。

```sig
gbpad.allNotesOff()
```

**パラメータ**

* なし

```blocks
input.onButtonPressed(Button.A, () => {
    gbpad.allNotesOff()
})
```

教室ではボタンに割り当てておくのがおすすめです。鳴りっぱなしになった音を止める
ブロック 1 つ分の薬になります。iPad が切断されたときも自動で止まります。
